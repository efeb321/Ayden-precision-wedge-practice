# Ayden Precision Coach — Beta

This is the separate testing version.

## To test on a computer
Open `index.html`.

## To publish on GitHub Pages
Upload the contents of this folder to a public GitHub repository.
Then enable GitHub Pages from the `main` branch and `/ (root)`.

## Important
This beta uses separate browser storage keys and cannot overwrite the future live app's data.

## What's new in this version
- Practice range now starts at 70-110 yards (Tier 1). After 3 Distance
  Ladder sessions in a row average under 2.5 yards of carry error, the
  app shows a banner and an "Expand the practice range" button that
  widens to 60-120 (Tier 2), then 50-130 (Tier 3). This is a manual,
  coach-controlled action — it never expands on its own.
- Every shot screen now shows a short "GCQuad focus" banner explaining
  which numbers matter most for that drill (start line, distance,
  trajectory, or spin) and why.
- A "GCQuad Numbers Guide" is available from the start screen and from
  the shot entry screen, explaining what each GCQuad number is, why it
  matters for wedge play, and typical elite wedge ranges.
- Inline one-line hints now sit under each GCQuad detail field for a
  quick reference while entering data.
